# 새 PC에서 처음부터 확인하기 (제3자 테스트 순서)

ktrade를 한 번도 깐 적 없는 PC에서, 처음 받는 사람 입장으로 설치 → 데이터 받기 → 백테스트 로그인 → 자동매매 시작까지 확인하는 순서입니다.
관리자(이용 코드를 발급하는 사람)가 할 일과 테스트하는 사람이 할 일을 나눠 적었습니다.

준비물: Windows 10/11, 인터넷, 키움 REST API **모의투자** 앱키·시크릿키(openapi.kiwoom.com에서 발급).
처음엔 반드시 **모의투자 키**로 하세요 — 실전 키는 실전 주문 동의 전에는 주문하지 않지만, 테스트에 실전 계좌를 쓸 이유가 없습니다.

## 0. 관리자: 이용 코드 발급 (관리자 PC에서)

백테스트는 이용 코드로 추가 로그인해야 열립니다. 서명 키(`~/.ktrade/admin/signing_key`)가 있는 PC에서만 발급할 수 있습니다.

```bash
ktrade admin issue tester1 --days 30 --note "새 PC 테스트"
```

또는 대시보드 🛠️ 관리자 탭에서 아이디·기간을 넣고 발급합니다. 나온 **아이디**와 **이용 코드(`KT1.`로 시작)** 를 테스트하는 사람에게 전달하세요.
코드는 서버 없이 어느 PC에서나 확인되고(공개 키로 서명만 확인), 만료일이 지나면 저절로 막힙니다.

## 1. 설치

1. [ktrade-setup.exe](https://github.com/Re-qwer3618/ktrade-public/releases/latest/download/ktrade-setup.exe)를 받아 더블클릭.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** (서명하지 않은 설치 프로그램이라 뜹니다).
2. '다음'만 누릅니다. 설치 중 인터넷에서 uv(파이썬 도구)와 ktrade 최신 릴리스를 받습니다 — 관리자 권한·파이썬 설치 필요 없음.
3. 마지막 화면 **ktrade 대시보드 열기** → 브라우저에 화면이 열립니다. 바탕화면에 'ktrade 대시보드'·'ktrade 명령창'·'ktrade 폴더'가 생깁니다.

확인할 것: 사이드바 맨 위 버전이 `0.7.0` 이상인지. 실패하면 `%LOCALAPPDATA%\ktrade-setup\install.log`.

## 2. 키움 로그인 (데이터 없이도 바로 대시보드)

로그인하면 차트 데이터를 받지 않아도 대시보드가 열립니다 — 위쪽 '마지막 일봉'이 '받지 않음 (선택)'이면 정상입니다.
운영 탭(조건식 자동매매)·영웅문 조건식·매매 기록은 데이터 없이 씁니다. 차트 데이터는 백테스트·계획용으로 고를 때만 받습니다.

## 3. (선택) 백테스트·계획용 데이터 받기

1. 사이드바 **🔑 키움 로그인** → 앱키·시크릿키, 키 종류 **모의투자** → **연결 확인 후 저장**.
   키는 Windows 자격 증명 관리자에 저장됩니다(파일에 남지 않음).
2. **📥 데이터** 탭(또는 🧪 백테스트 탭에 데이터가 없을 때 나오는 칸)에서 종목 몇 개와 기간을 정하고 **받기**.
   - (선택) **📁 저장 위치 바꾸기** 로 데이터를 둘 폴더를 고릅니다 — 다른 드라이브(예: `D:\ktrade-data`)도 됩니다. 기본은 `%USERPROFILE%\.ktrade\data`.
3. 대시보드 **📥 데이터** 탭에서 받을 범위를 넓힙니다.
   - 시장(거래소·코스닥·ETF), 뺄 종류(ETF·ETN·스팩·리츠·우선주), 투자유의 제외, 전일 종가·시가총액 범위
   - 기간(시작일·끝일 또는 '오늘까지'), 봉 종류(일봉·N분봉·N틱)
   - **저장** → 아래 '범위에 드는 종목'에서 대상 종목을 미리 보고 **지금 받기**
   - 전 종목 몇 년치는 처음 몇 시간 걸립니다 → 'ktrade 명령창'에서 `ktrade collect` 권장(꺼져도 이어받기)
4. 받은 것 확인: 데이터 탭 위쪽 숫자·용량, **📈 종목 차트** 탭(일봉·분봉·틱, 이동평균선·거래량).

명령창으로 하면:

```bash
ktrade collect --dry-run                                  # 받을 범위만 보기
ktrade collect --symbols 005930,000660 --years 3          # 몇 종목만
ktrade collect --price-min 1000 --cap-min 500 --limit 100 # 시장 범위에서 100종목
ktrade data                                               # 받아 둔 범위·용량
ktrade data-dir D:\ktrade-data                            # 저장 위치 바꾸기 (기존 데이터도 옮김)
```

## 4. 백테스트 체험판 → 정식판 로그인 확인

1. 이용 코드 없이: **🧪 백테스트 체험판** 탭
   - '예제 매매조건': example_breakout 등을 내가 받은 데이터로 백테스트 → 결과가 나오면 성공.
   - '영웅문 조건식 테스트': 키움에서 조건식 목록을 불러와 10개까지 고르고 저장 → **관찰 시작**(장중). 다음 날 신호별 '그때 샀다면'이 쌓임.
   - 명령창 `ktrade test example_breakout`은 막히는지 확인(정식판 기능).
2. 사이드바 **🔓 백테스트 정식판 로그인** → 관리자에게 받은 **아이디·이용 코드** → **로그인**.
   - 사이드바에 '백테스트 정식판 · 아이디 · 만료일'이 보이고 탭 이름이 **🧪 백테스트 정식판**으로 바뀝니다.
   - '계획에 쓸 매매조건'에서 켜기·순서·파라미터·영웅문 조건식 조합을 저장할 수 있습니다.
   - 틀린 코드·다른 아이디·만료된 코드는 "로그인 실패"가 나와야 정상입니다.
3. 🧪 백테스트 탭에서 예제 조건(example_breakout 등)을 골라 실행 → 승률·95% 구간·시장 대비가 나오면 성공.
4. 명령창: `ktrade access status`(로그인 상태), `ktrade access login --id tester1`(코드는 물어봄), `ktrade access logout`.

로그인한 코드는 `%USERPROFILE%\.ktrade\access.json`에 저장돼 다음에 다시 넣지 않아도 됩니다. 키움 키와는 따로라, 키를 바꿔도 유지됩니다.

## 5. 자동매매 시작 (모의투자)

대시보드 **🕹️ 운영** 탭, 위에서부터 순서대로:

1. **1 · 조건식** — **키움에서 내 조건식 목록 불러오기**(영웅문에서 미리 만들어 둔 조건식) → 쓸 것에 체크, 매매/관찰 선택.
2. **2 · 익절·손절·추적 손절**, **3 · 분할매수·분할익절**, **4 · 리스크 한도**(하루 손실 한도·하루 수익 목표·시간 청산) — 0이면 끔.
3. **5 · 시작 / 중지** — 주문 방식 **가상 체결(paper)** 또는 **내 키움 계좌**(모의 키면 모의투자 서버) → **시작**.
   - 엔진(`ktrade hts watch`)이 따로 떠서 대시보드를 닫아도 계속 돕니다. 장중(09:00~15:30)에 편입 신호가 오면 설정대로 매수·매도.
   - 위쪽 상태 표시줄: 엔진 동작 여부, 오늘 손익, **긴급 정지**(오늘 신규 매수 중지 + 보유 전량 매도).
   - 아래 **실시간**: 편입 신호·보유·미체결·체결·로그.
4. 실전 키라면 5단계에서 **실전 주문 동의**를 해야만 실제 주문이 나갑니다(테스트에서는 하지 마세요).

장 마감 후 계획(매매조건) 방식:

- 정식판 **🧪 백테스트 → 계획에 쓸 매매조건**에서 켬(백테스트한 설정만 계획을 만듦).
- **🕹️ 운영** 탭 맨 위 **⏰ 자동 실행**에서 계획(daily)·실행(run) 시각·요일을 정하고 **저장하고 등록**.
- 조건식 매매와 겹칠 때는 4단계 **우선순위**(계획 우선 · 선착순 · 나눠 쓰기). 보유 종목의 매도는 산 쪽 엔진만 판단합니다.
- 결과는 **🗓️ 계획** 탭: 계획마다 매수함/안 삼과 이유, '계획대로였다면', 최근 N일 적중, 걸러진 계획.

명령창으로는:

```bash
ktrade daily                 # 장 마감 후: 수집 → 다음 거래일 계획
ktrade run                   # 장중: 계획대로 매수, 엔진 규칙대로 매도 (기본 paper)
ktrade schedule install      # 평일 자동 실행 (16:30 daily · 08:50 run)
```

## 6. 확인 체크리스트

| 항목 | 기대 결과 |
|---|---|
| 설치 | 바탕화면 바로가기 3개, 대시보드 버전 0.7.0 이상 |
| 데이터 없이 | 로그인만으로 운영·계획·조건식 탭이 열림 |
| 체험판 | 예제 매매조건이 내 데이터로 백테스트됨, 조건식 테스트 저장·관찰 시작 |
| 키움 로그인 | 모의 키로 '연결 확인 후 저장' 성공 |
| 데이터 받기 | 데이터 탭 숫자·용량이 늘고, 차트 탭에 일봉이 보임 |
| 저장 위치 | 바꾼 폴더에 `market.db`·`market\`가 생김 |
| 백테스트 잠금 | 코드 없이 🔒, 코드 로그인 후 열림, 틀린 코드는 실패 |
| 자동매매 | 운영 탭 시작 → 상태 표시줄 '동작 중', 장중 신호·로그가 쌓임 |
| 긴급 정지 | 누르면 오늘 신규 매수 중지 표시 |

## 다 쓴 뒤 지우기

설정 → 앱 → ktrade 제거(자동 실행·바로가기·프로그램 삭제). 데이터·설정 `%USERPROFILE%\.ktrade`(와 바꿨다면 데이터 폴더)는 남으니 직접 지우세요.
키움 키는 대시보드 **로그아웃** 또는 `ktrade logout`으로 지웁니다.
